SerbTracker Client — User Guide

1) What is this app for?

The app helps the driver or field rep to:

  • Sign in with their account.
  • View daily service orders.
  • Start and end each service with odometer validation.
  • Enable tracking and send the current location.
  • Change app and tracking settings.

2) First launch — Sign in

  1. The Sign in screen appears.
  2. Enter your username and password.
  3. Tap the sign-in button.
  4. After success you go to the main screen automatically.

The app keeps your session; you usually will not need to sign in every time until you log out.

3) Main screen after sign-in

  • Top bar: welcome, username, log out.
  • Bottom bar (3 tabs): Services — Tracking — Settings.

4) Services screen

Your main day-to-day screen.

Title and search

The search button opens a search sheet; you can search by order number, customer, reference, vehicle, or service type.

Filters

All, Not started, In progress, Completed — each with a count badge.

Service card and Start / End

  • Not started → Start button.
  • In progress → End button.
  • Completed → no action button.

In Arabic UI the action button leans left; in English it leans right.

5) Starting a service

  1. Tap Start.
  2. The confirmation dialog shows reference, service type, and start odometer.
  3. Tap Start again to confirm.

After success the status becomes In progress and a success message appears.

6) Ending a service

  1. Tap End.
  2. Enter the end odometer.
  3. The app checks: valid number, end ≥ start, and distance within the allowed limit (e.g. a large km cap).

7) Tracking screen

  • Turn continuous tracking on or off.
  • Send current location manually.
  • Open Logs / Status.
  • Send an SOS emergency signal when needed.

The app may ask for location permission or battery settings depending on the device.

9) Settings

General

Language, appearance (light / dark / system), app version, log out.

Location and advanced

Accuracy, distance, intervals, heartbeat, and advanced options (e.g. offline buffering). Changes apply to the tracking service.

10) Log out

From the header icon or Settings. After confirmation: tracking stops, session clears, back to sign-in.

11) Common issues

  • No services shown: check network and account; try refresh / retry.
  • Start or end fails: read the message; verify odometer.
  • Background tracking: location permission and battery optimisation.
  • Language / theme: leave and reopen the screen; confirm the choice was saved.

12) Suggested daily workflow

  1. Confirm you are signed in.
  2. Review services and filters.
  3. Start a service when work actually begins.
  4. End it right away with a correct odometer.
  5. Use Tracking to send location when needed.
  6. Log out at end of shift.

13) Quick demo script (3–5 minutes)

  1. “This is sign-in — enter username and password.”
  2. “After login we get the main screen with three tabs.”
  3. “On Services: search, filters, and order cards.”
  4. “Start for new orders, End for in-progress ones.”
  5. “On Tracking: toggle tracking, send location, logs, SOS.”
  6. “In Settings: language, theme, tracking options.”
  7. “Log out from the top or Settings.”
