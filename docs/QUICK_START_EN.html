SerbTracker Client - Quick Start (One Page)

1) Sign In

  • Open app, enter Username and Password.
  • Tap Sign in.

2) Main Navigation

  • Tabs: Services, Tracking, Settings.
  • Top header shows username + Logout.

3) Services (Daily Workflow)

  • Use filters: All / Not started / In progress / Completed.
  • Use search by number, customer, reference, vehicle, or type.
  • Review card details: time, customer, vehicle, Adults/Children, odometer.

4) Start Order

  • Tap Start, confirm start meter.
  • Status changes to In progress.

5) End Order

  • Tap End, enter end meter.
  • End meter must be >= start meter and within allowed distance.
  • Status changes to Completed.

6) Tracking

  • Enable/disable tracking in Tracking tab.
  • Use Send location when needed.
  • Use Show status for logs/diagnostics.

flutter_background_geolocation Features

  • Background tracking even when app is not foregrounded.
  • Start/stop tracking service from app controls.
  • Manual current-position send.
  • Motion-state aware tracking behavior.
  • Dynamic tracking config updates from Settings.
  • Offline Support: if internet is unavailable 📵, data is buffered and sent when connection returns.
  • Permission and battery-optimization handling prompts.
  • Tracking service stops on logout.

7) Settings

  • Language: System / Arabic / English
  • Appearance: System / Light / Dark
  • Adjust tracking settings (ID, URL, accuracy, intervals, ...)

8) Logout

  • Tap logout icon next to username.
  • Session is cleared and tracking stops.

Quick Troubleshooting

  • No services: check internet/account, then tap Retry.
  • Cannot start/end: verify odometer value and validation message.
  • Tracking issue: grant location permission and disable battery optimization.
